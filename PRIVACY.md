# Privacy Policy – KOReader Google Drive Plugin

_Last updated: 2026-10-25_

This is a personal, non-commercial tool used only by its author to read their own books from Google Drive on an e-reader (KOReader) and with rclone on a desktop computer.

**Data accessed.** The app requests read-only access to Google Drive (`drive.readonly`) or Drive access via rclone. It only lists file/folder metadata (names, sizes, dates) and downloads files the user chooses to read.

**Where data goes.** All data stays on the user's own devices (e-reader and computer). Nothing is sent to any server operated by the author or any third party. No analytics, no advertising, no data sale or sharing.

**Storage.** OAuth tokens and a local catalog of file metadata are stored only on the user's device. Downloaded books are stored locally and can be deleted at any time.

**Revoking access.** Access can be revoked at any time at https://myaccount.google.com/permissions.
